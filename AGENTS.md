# Project Instructions

## Bookkeeping

- Read `bookkeeping/README.md` before editing financial records.
- Preserve financial history; never delete transactions or overwrite original imports.
- Never guess missing financial values. Flag them for review.
- Keep Clear Path Junk Removal activity separate from unrelated ventures, even when they share an account.
- Run `python bookkeeping/scripts/validate_bookkeeping.py` after every bookkeeping change.
- Regenerate reports with `python bookkeeping/scripts/generate_reports.py` after every confirmed bookkeeping change.
