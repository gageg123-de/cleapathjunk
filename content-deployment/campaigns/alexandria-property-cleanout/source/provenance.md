# Source provenance

The repository did not contain local image files at task start. On 2026-08-20, ten existing Clear Path production job photographs were copied from the public Alexandria project page asset set into this immutable campaign source folder:

- Project: https://clearpathjunkla.com/projects/alexandria-duplex-cleanout/
- Asset base: `https://clearpathjunkla.com/assets/images/cook-ave/`
- Production page description: Alexandria property cleanout with household debris removed from multiple rooms and the covered porch.

The production page explicitly presents the ten images as five before/after pairs. The files in this folder are source copies and must not be overwritten. Processed derivatives belong elsewhere in the campaign.

File hashes are recorded in `source-hashes.sha256` after validation.
